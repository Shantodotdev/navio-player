# Navio Connect: Feature Overview

This document outlines the user-facing feature requests for Navio Connect, enabling multi-device control and local media streaming across desktop and mobile devices.

---

## 1. Desktop-to-Desktop Features (Windows, macOS, Linux)

- **Automatic Local Discovery**
  - All Navio desktop apps on the same Wi-Fi or home network automatically discover each other without manual setup.
  - Devices are identified by friendly names (e.g., "Living Room PC", "MacBook Pro").

- **Remote Playback Control**
  - Control media playing on another computer directly from your current machine.
  - Full remote controls: Play, Pause, Seek/Scrub timeline, Adjust volume, Next/Previous track, and Jump to specific queue items.
  - Live "Now Playing" sync: See real-time title, artwork, playback progress, and current queue of the target device.

- **Cross-Desktop Media Streaming ("Play Here")**
  - Browse media files and playlists stored on one desktop from another desktop.
  - Stream videos and audio files hosted on another machine directly inside your current Navio player without manually copying files.

- **Security & Connection Permissions**
  - Simple one-click approval or PIN verification when a new device attempts to connect for the first time.
  - Manage trusted devices and revoke permissions at any time.

---

## 2. Mobile Experience (Web / PWA)

- **No Native App Installation Required**
  - Access Navio from any mobile phone or tablet using a modern web browser.
  - Installable as a standalone app icon on the home screen (PWA) on iOS and Android.

- **Instant QR Code Onboarding**
  - Desktop displays a scannable QR code to instantly pair and launch the mobile interface.

- **Touch-Friendly Mobile Remote**
  - Control desktop playback while away from the keyboard (couch, bed, across the room).
  - Mobile-optimized controls with large touch targets for play/pause, volume slider, progress scrubber, and queue management.
  - Native lock-screen media controls (play/pause and skip tracks from the phone's lock screen or notification center).

- **Mobile Media Streaming**
  - Browse your desktop's full video and audio collection from your phone.
  - Stream any audio track or video directly on your mobile device over local Wi-Fi.
